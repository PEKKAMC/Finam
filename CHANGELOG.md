# Finam v0.3.0-beta

**Release Date:** October 8, 2026

> **⚠️ BETA WARNING: Read Before Using**
>
> Welcome to the Beta build! Core stability and performance have been significantly improved since our Alpha release, but you may still encounter occasional bugs, minor performance hiccups, or incomplete features as we fine-tune the application for full launch.
>
> * **Data Backup:** While local database corruption is now far less likely, we still recommend backing up any critical financial data before performing major updates or operations.
> * **Feedback:** If you run into any issues, softlocks, or unexpected behavior, please submit a report via our GitHub page.
>
> Thank you for helping us test and polish this release!

## Features in this version

This version mostly works on improving the performance of the application, as well as the implementation of AI features. These features include:

*   **Purchase Advisor**: The AI can now provide advice on purchases based on your spending habits and financial goals.
*   **AI messages**: Greeting messages, tips, and other helpful information are now generated by the AI to enhance your experience.
*   **Better performance**: The application has been optimized for smoother navigation, faster load times, and reduced memory usage.
*   **Codebase refactoring**: The source code has been cleaned up and reorganized for better maintainability and future development.
*   **Financial chart refresh**: The financial chart logic and visuals were reworked for improved clarity and presentation.
*   **View caching**: Added cached view support to reduce unnecessary rebuilds and improve responsiveness.

## Changes in this version

*   Merged saving_dialog package from global_components with savings page, because it is only used there.
*   Renamed "lesson" and "saving" pages to "lessons" and "savings".
*   Finalized the home page experience, including updated components and layout adjustments.
*   Reworked the financial chart to improve data display and reduce logic issues.
*   Improved the view-building and page initialization flow for better performance.
*   Added cached views to reduce redundant UI rebuilds and improve responsiveness.
*   Updated language files and renamed components to keep the app text and structure consistent.
*   Removed legacy lesson content and related source code to streamline the project.
*   Added support for deleting all user data and improved related dialog behavior.
*   Refined the purchase scanner workflow and updated related logic.
*   Cleaned up syntax and naming issues for readability and maintainability.

## Bug fixes in this version

*   Elements are no longer obstructed by the operating system.
*   Fixed minor issues and crashes.
*   Fixed starter page dialogs not showing after the first use.
*   Fixed user dialogs not updating correctly.
*   Fixed logic errors affecting app flow and chart behavior.
*   Fixed several dialog-related bugs and deletion flows.
*   Improved app stability during view updates and page transitions.

## Known Issues & Instability

*   Some actions may cause softlocks or crashes.
*   Lesson player and lesson editor UI don't fit the screen.
*   The Purchase Scanner AI might not work some (A LOT OF) times.
*   Various UI elements may not scale perfectly on all screen sizes.
